Primera publicación de SIGRA Mobile. Aplicación Android experimental para explorar
el catálogo oficial de SIGRA y participar en su red ciudadana.

- Inicio, Mapa, Sismos, Alertas y Ajustes en páginas independientes.
- Seis fuentes oficiales: SGC, USGS, EMSC, GeoNet, GEOFON e INGV.
- Filtros de periodo, magnitud, fuente, radio y orden; búsqueda y detalles.
- Tema oscuro/claro/automático, tipografías locales y mapa adaptado al tema.
- Historial persistente de alertas, deduplicación y diagnóstico de conexión.
- Monitoreo experimental por acelerómetro, con permisos y servicio en primer plano.

Android 8.0 o posterior. Paquete de distribución: `com.sigra.app`, versión
`1.0.0.0`, código `2`. La instalación de desarrollo `com.sigra.app.debug` es una
aplicación distinta y no comparte preferencias con esta distribución.

Descarga `sigra-v1.0.0.0.apk`. `SHA256SUMS` permite comprobar la integridad.
La publicación es experimental; no certifica capacidad de alerta temprana.

El APK se genera con Kotlin 2.0.21 y las herramientas Android (AAPT2, D8,
zipalign y apksigner), usando las dependencias locales previamente resueltas por
Android Studio. Se conserva el certificado para futuras actualizaciones.
La comprobación visual de instalación, permisos, sensores y avisos requiere un
Android real. SIGRA no garantiza avisos anticipados ni sustituye a las autoridades.
